NOVA DRIFT is a neon twin-stick arena shooter. Pilot a lone ship through waves of drones, weavers and splitters, chain kills into a combo multiplier, grab spread, rapid-fire, shield and bomb power-ups, and face the Void Titan boss every fifth wave. Three lives, a persistent best score, synthesized WebAudio sound, and a full loop from title screen to game over and restart — all in plain static files, no network, no library.

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080
```
